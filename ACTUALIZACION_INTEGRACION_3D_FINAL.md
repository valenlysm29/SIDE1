# Actualización de integración 3D

Cambios aplicados en esta versión:

- Se agregó un estado persistente del mundo empresarial.
- Se añadió un puente para que decisiones puedan reflejarse en elementos 3D.
- Se preparó almacenamiento de:
  - máquinas instaladas;
  - tiendas desbloqueadas;
  - inventario visible.
- Se mantiene la lógica existente de decisiones, producción, ventas y finanzas.
