# MakeHuman graphical assets

The character geometry, proxy meshes, skinning weights and authored textures
used by `assets/models3d/npc_realistic_*.glb` are derived from MakeHuman
graphical assets explicitly released under CC0. The MakeHuman application
source code is not included or imported by this character exporter.

Core source revision: a8bc2d54ff0ac92e78ff71431b1023eda42bf482.
Repository: https://github.com/makehumancommunity/makehuman

System asset pack:
https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html

Downloaded archive:
https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip

Full CC0 legal text: `tools/character_sources/LICENSE.ASSETS.md`.
License distinctions: `tools/character_sources/LICENSE.md`.
Individual file origins and hashes: `tools/character_sources/SOURCE.json` and
`tools/character_sources/system_assets/SOURCE.json`.

Historical graphical asset contributors credited in the sources include
Data Collection AB, Joel Palmius and Jonas Hauquier. The exporter preserves
the asset headers in the source files.
